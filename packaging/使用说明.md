# YuE2 Studio 使用说明

Windows（CUDA / CPU）与 macOS（Apple Silicon MPS / MLX）通用。

## 快速开始

1. 安装 **Python 3.10+**（Windows: [python.org](https://www.python.org/downloads/)，安装时勾选 *Add to PATH*；macOS: `brew install python@3.12` 或 python.org 安装包）
2. 双击启动器：
   - **Windows**：`start.bat`
   - **macOS / Linux**：`start.command`（第一次可能需要右键 → 打开，或在终端执行 `chmod +x start.command`）
3. 首次运行会自动完成：创建 `.venv` → 安装依赖（约 1–2 GiB，经镜像下载）→ 下载核心模型（约 7.3 GiB）→ 启动服务并打开浏览器 `http://127.0.0.1:7860`

之后每次双击启动器即可直接进入界面。**其余组件**（旧版/合并解码器、LoRA 风格、音频转录、MLX 各变体）启动后在侧栏「模型」页按需下载——页内可切换「国内镜像 / 国际直连」两种下载源，支持断点续传与取消，下载不阻塞生成。

依赖安装或模型下载中断后重新双击/重新下载即可续传。

## 内嵌模型包（免首启下载，分卷分发）

如果你拿到的是**内嵌模型的一键包**（文件名形如 `yue2-studio-oneclick-<平台>-<档位>-<日期>.zip.part-aa` 等一系列分卷），模型已随包携带，首次运行只装依赖、不下载模型。按机器选一个档位即可：

| 平台 | 档位 | 内含模型 | 体积 | 适用机型 |
|---|---|---|---|---|
| macOS | mini | MLX 4bit + Vae | ≈4.5 GB | 16 GB 内存，省内存优先 |
| macOS | standard（推荐） | MLX 8bit + Vae | ≈5.3 GB | 16 GB+ 内存 |
| macOS | full | torch 3B + MLX 三档 + 全部解码器/LoRA/转录 | ≈26 GB | 32 GB+ 内存，全功能 |
| Windows | standard | torch 3B + Vae | ≈7.4 GB | NVIDIA 显卡（CUDA）或 CPU |
| Windows | full | 全部 torch 系模型 | ≈12.4 GB | 同上，全功能 |

**合并分卷**（在包含全部分卷的目录执行，产物为完整 zip）：

- **macOS**（终端）：
  ```bash
  cat yue2-studio-oneclick-*.zip.part-* > merged.zip
  ```
- **Windows**（命令提示符 cmd，在下载目录）：
  ```cmd
  copy /b yue2-studio-oneclick-*.zip.part-* merged.zip
  ```

**校验完整性**（可选但推荐）：合并后对照随附的 `….zip.sha256` 清单最后一行——macOS 用 `shasum -a 256 merged.zip`，Windows 用 `certutil -hashfile merged.zip SHA256`，两者应一致。

然后解压 `merged.zip`，按上面「快速开始」从第 2 步继续。包内未包含的可选组件（如 Windows 标准档的转录栈），之后仍可在「模型」页按需下载。

## 可选组件（应用内「模型」页，或首次运行询问/手动安装）

| 组件 | 作用 | 安装命令 |
|---|---|---|
| 扩展模型 | 旧版（基准）解码器 + 合并 0.666 解码器 + 3 个 LoRA 风格适配器 + realaudio 重建包（约 1.5 GiB） | `python tools/hf_download.py extras` |
| 音频转录 | 上传音频 → 转乐谱 → 翻唱（SheetSage2 + MERT，约 2.6 GiB） | `python tools/hf_download.py transcribe` |
| MLX 引擎 | Apple Silicon 原生推理，约 5 倍速度（约 4.2 GiB，仅 macOS） | `python tools/hf_download.py mlx` |

- 全部安装（推荐）：`python tools/bootstrap.py --yes`（首次运行会自动执行）
- 运行后也可以在「模型」页逐个下载与切换下载源
- 只检查环境：`python tools/bootstrap.py --skip-deps --skip-models`

## 平台差异

| 能力 | Windows | macOS |
|---|---|---|
| 推理设备 | CUDA（检测到 NVIDIA 显卡）或 CPU | Apple Silicon（MPS） |
| FP8 量化 / AR 卸载 / 显存预算 | ✅ 设置里可见（CUDA） | 显存预算可用；FP8 不适用 |
| MLX 引擎 | — | ✅ 设置 → 模型胶囊 → 推理引擎 |
| vLLM 后端 | 需自行 `pip install vllm`（原生 Windows 不支持，需 WSL2） | — |

## 常见问题

- **端口被占用**：默认 `127.0.0.1:7860`；关闭占用进程或修改 `web/server.py` 末尾的 `port=`。
- **模型下载慢或失败**：下载器默认走 `hf-mirror.com`；可用环境变量 `YUE2_HF_ENDPOINT` 换源。重新执行下载命令会自动续传并校验 SHA-256。
- **想用指定的 CUDA 版 PyTorch**：安装前设置 `YUE2_TORCH_INDEX=https://download.pytorch.org/whl/cu128` 再运行 bootstrap。
- **中文风格提示词支持哪些词**：完整词表见 `docs/style-terms.md`；未收录的中文词会原样保留。
- **想用 LLM 增强风格提示词 / 试聊**：侧栏「LLM 配置」→「新建供应商」选平台预设（DeepSeek、通义千问、智谱、Kimi、MiniMax、OpenAI、Ollama 或自定义），「拉取模型」一键列出可用模型；保存后自动测连通，页面下方「试聊」面板可直接对话（流式、会话保存在本机）。配置后魔法棒支持 LLM 增强，中文风格的翻译也会更聪明。
- **环境重置**：删除 `.venv/`（或 Windows 下手动删）后重新双击启动器；模型文件在 `models/` 下可单独删除重下。
- 生成的内容、库数据保存在 `outputs/` 与 `web/data/`，删除即清空。

## 仓库开发者：构建一键包

一键包由 `packaging/` 构建、产出到 `oneclick-packages/`（产物不入 git）：

```bash
python packaging/build_package.py            # 构建 → oneclick-packages/yue2-studio-oneclick-<日期>.zip
python packaging/build_package.py --keep-stage   # 保留暂存目录便于排查
```

- 包内 = 启动器（`packaging/launchers/`）+ 本说明 + 应用源码；**不含**模型、虚拟环境、输出、用户数据（构建脚本带安全反扫）。
- 本仓库自用启动（无需构建包）：`python tools/start.py`。
- 内嵌模型包由 `packaging/build_model_bundle.py` 构建（CI 现场下载模型、流式打包、按 ≤1.9 GiB 分卷），档位定义见脚本内 `TIERS`；本机验证用 `--use-local-models`。包内含 `models/.bundle` 标记：首启检测到任一可用引擎（torch core 或任一 MLX 变体）即跳过全部模型下载。
