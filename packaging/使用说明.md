# YuE2 Studio 使用说明

Windows（CUDA / CPU）与 macOS（Apple Silicon MPS / MLX）通用。

> 本包是**平台专用包**：只带当前平台的启动器（macOS 为 `start.command`，Windows 为 `start.bat`），不会混入另一平台的启动器。请从 GitHub Releases 下载与系统对应的包。

> **包内自带便携 Python 与全部依赖**：不需要安装 Python、不需要联网装依赖，解压后双击启动器直接打开网页。

## 从哪里下载

GitHub Releases 里有两种入口，包内容一致（都是不含模型的瘦包）：

| 入口 | 说明 |
|---|---|
| 版本 tag（如 `v0.1.8`） | 正式版本，`mac` 与 `win` 两个包 + 同名 `.sha256`；推荐使用 |
| `oneclick-latest` | 滚动最新构建，每次 push main 覆盖更新，适合尝鲜/排查 |

下载后可用 `shasum -a 256 <包名>.zip`（macOS）或 `certutil -hashfile <包名>.zip SHA256`（Windows）对照 `.sha256` 校验。

## 快速开始

1. 解压 zip（建议放在有 10 GB 以上可用空间的目录）
2. 双击启动器（本包只有当前平台的那一个）：
   - **Windows**：`start.bat`
   - **macOS**：`start.command`（第一次可能需要右键 → 打开，或在终端执行 `chmod +x start.command`）
3. 数秒后浏览器自动打开 `http://127.0.0.1:9086`（默认端口；冲突时见下方「端口被占用」）。**一键包不含模型**：页面会停在左侧「模型」页，点「核心模型」下载（约 7.3 GiB），下载源可选「国内镜像 / 国际直连」。

之后每次双击启动器即可直接进入界面。所有模型组件（核心模型、旧版/合并解码器、LoRA 风格、音频转录、MLX 各变体、Windows CUDA 加速套件）都在侧栏「模型」页按需下载——页内可切换「国内镜像 / 国际直连」两种下载源，支持断点续传与取消，下载不阻塞生成。

> 包体积约 300–400 MB（自带 Python 运行时与依赖）；首次启动只需几秒，不会联网安装任何东西。模型下载中断后重新下载即可续传。

## 下载源：国内网络 / 国外网络

所有模型都是**下载获得**的，不随包分发。首次进入「模型」页时先选下载源：

| 下载源 | 端点 | 适用网络 |
|---|---|---|
| 国内镜像（默认） | `hf-mirror.com` | 中国大陆，直连即可 |
| 国际直连 | `huggingface.co` | 海外，或可自由访问外网的环境 |

- 页面顶部「下载源」分段控件可随时切换，只影响之后发起的下载；
- 命令行下载同样支持 `--source mirror` / `--source huggingface`（用包内解释器，见下）；
- 没切换过时默认国内镜像；选择会记到本机设置里，下次启动沿用。

## Windows：CUDA 加速套件（NVIDIA 显卡，可选）

包内默认是 **CPU 版 PyTorch**，所有机器都能启动与运行。若你的 Windows 机器有 **NVIDIA 显卡**，可在「模型」页下载「CUDA 加速套件」（约 3 GB，分卷下载、断点续传）来启用 GPU 加速：

1. 打开「模型」页 → 找到 **CUDA 加速套件**（仅 Windows 显示；页面会先检测 `nvidia-smi` 是否可见显卡）；
2. 点「下载」，等待分卷校验与安装完成；
3. **重启应用**（关闭终端窗口后重新双击 `start.bat`），状态变为「已启用」即生效；
4. 想回退 CPU：在同一位置点「移除」，重启应用即可。

说明：套件是与应用 torch 版本匹配的 cu128 torch 树，单独发布、不进主包（否则会超过 GitHub 单文件 2 GB 限制）；下载失败可重试，已下载分卷会续传；应用升级后若 torch 版本变化，套件会提示「需重新下载」。

## 可选组件（应用内「模型」页，或命令行）

| 组件 | 作用 | 安装命令（包内解释器） |
|---|---|---|
| 扩展模型 | 旧版（基准）解码器 + 合并 0.666 解码器 + 3 个 LoRA 风格适配器 + realaudio 重建包（约 1.5 GiB） | `./runtime/bin/python3 tools/hf_download.py extras`（Windows：`runtime\python.exe tools\hf_download.py extras`） |
| 音频转录 | 上传音频 → 转乐谱 → 翻唱（SheetSage2 + MERT，约 2.6 GiB） | `… tools/hf_download.py transcribe` |
| MLX 引擎 | Apple Silicon 原生推理，约 5 倍速度（约 4.2 GiB，仅 macOS） | `… tools/hf_download.py mlx` |
| CUDA 加速套件 | Windows + NVIDIA 显卡的 GPU 加速（约 3 GB，仅 Windows） | 建议在「模型」页点击下载（带进度/取消/断点续传） |

- 推荐路径：应用内「模型」页逐个下载（可切换下载源、看进度、可取消）
- 命令行一次装齐（含核心模型与扩展，用包内解释器）：macOS `./runtime/bin/python3 tools/bootstrap.py --models --extras --transcribe --mlx`；Windows `runtime\python.exe tools\bootstrap.py --models`（+`--extras --transcribe`，NVIDIA 显卡用模型页的 CUDA 套件）
- 从源码开发（克隆仓库，非一键包）：`python tools/bootstrap.py --yes` 只准备环境，`python tools/start.py` 启动

## 平台差异

| 能力 | Windows | macOS |
|---|---|---|
| 推理设备 | CUDA（安装 CUDA 加速套件后）或 CPU | Apple Silicon（MPS） |
| FP8 量化 / AR 卸载 / 显存预算 | ✅ 设置里可见（CUDA） | 显存预算可用；FP8 不适用 |
| MLX 引擎 | — | ✅ 设置 → 模型胶囊 → 推理引擎；或模型页下载 MLX 变体 |
| vLLM 后端 | 需自行安装（原生 Windows 不支持，需 WSL2） | — |

## 常见问题

- **端口被占用**：默认 `127.0.0.1:9086`；无需改代码，可用环境变量或启动器参数换端口——macOS：`YUE2_PORT=9090 ./start.command` 或 `./start.command --port 9090`；Windows：命令行 `set YUE2_PORT=9090` 后运行 `start.bat`（或 `start.bat --port 9090`）。
- **模型下载慢或失败**：在「模型」页把下载源切到「国内镜像（hf-mirror.com）」或「国际直连（huggingface.co）」后重试；命令行可加 `--source mirror` / `--source huggingface`，或用环境变量 `YUE2_HF_ENDPOINT` 指定端点。已下载分片会自动续传并校验 SHA-256。
- **Windows 想用 NVIDIA GPU 加速**：按上文「CUDA 加速套件」在模型页下载并重启；套件下载失败可重试续传。
- **启动很慢 / 打不开**：确认解压完整（包内应有 `runtime/` 与 `envs/` 目录）；macOS 首次打开 `start.command` 可能被 Gatekeeper 拦截，右键 → 打开即可。
- **中文风格提示词支持哪些词**：完整词表见 `docs/style-terms.md`；未收录的中文词会原样保留。
- **想用 LLM 增强风格提示词 / 试聊**：侧栏「LLM 配置」→「新建供应商」选平台预设（DeepSeek、通义千问、智谱、Kimi、MiniMax、OpenAI、Ollama 或自定义），「拉取模型」一键列出可用模型；保存后自动测连通，页面下方「试聊」面板可直接对话（流式、会话保存在本机）。配置后魔法棒支持 LLM 增强，中文风格的翻译也会更聪明。
- **环境重置**：整个目录删掉重新解压即可（模型与设置都在包内 `models/`、`web/data/`，可单独删除重下）。
- 生成的内容、库数据保存在 `outputs/` 与 `web/data/`，删除即清空。

## 仓库开发者：构建一键包

构建器默认产出**自包含**平台包（便携 Python + 预装依赖；产物输出到 `oneclick-packages/<平台>/`，不入 git）：

```bash
python packaging/build_package.py --platform macos     # → oneclick-packages/macos/yue2-studio-oneclick-<日期>-macos.zip
python packaging/build_package.py --platform win-x64   # → oneclick-packages/win-x64/yue2-studio-oneclick-<日期>-win-x64.zip
python packaging/build_package.py --platform macos --runtime slim   # 开发用瘦包（首次启动仍走 bootstrap）
python packaging/smoke_package.py oneclick-packages/macos/*.zip      # 条目冒烟 + .sha256
python packaging/smoke_bundle.py  oneclick-packages/macos/*.zip      # 真冒烟：包内 Python 起服务并轮询 /api/state
```

- 包内 = 本平台启动器 + 本说明 + 应用源码 + `runtime/`（python-build-standalone）+ `envs/web`（+ macOS `envs/mlx`）；**不含**模型、输出、用户数据（构建脚本带安全反扫）；另一个平台的启动器会被红线拦截。
- 便携 Python 与 pip wheel 会缓存在 `YUE2_ONECLICK_CACHE`（默认 `~/Library/Caches/yue2-oneclick` / `%LOCALAPPDATA%\yue2-oneclick`）；CI 用 `actions/cache` 复用。
- 候选发布：push main 覆盖滚动 release `oneclick-latest`；打 `v*` tag 走正式发布——`prepare` 建草稿 → mac/win 并行构建 + 冒烟 → 上传 zip/sha256 → 双平台全绿后自动转正式。
- Windows CUDA 加速套件由 `packaging/build_cuda_kit.py` 构建（`cuda-kit.yml` 手动触发），发布到独立 tag `cuda-kit-cu128-torch<版本>`，应用通过 `tools/cuda_kit.json` 里的 manifest URL 下载。
- 本仓库自用启动（无需构建包）：`python tools/start.py`。
